# find_from

Плагин Roundcube (плюс бонус-аддон листинга) для ветки 1.7.x.

## Что делает

### Поиск по отправителю (контекстное меню)

Правый клик по письму в списке → три пункта:

* **Найти письма от отправителя** — поиск `from:email`;
* **Найти письма этому отправителю** — поиск `to:email`;
* **Найти письма с домена отправителя** — поиск `from:@domain`.

Адрес отправителя передаётся в клиент из хука `messages_list`
(`extra_flags.find_from`), поэтому меню работает без дополнительных
запросов к IMAP.

**Зависимость:** плагин [`contextmenu`](https://packagist.org/packages/sblaisot/contextmenu)
— именно он рисует контекстное меню списка (`contextmenu_init`).
Без него плагин работает, но пункты меню не появятся.

### folder_badge (входит в комплект)

`folder_badge.js` / `folder_badge.css` добавляют бейдж с именем папки рядом
с темой письма в многокорпусных листингах (например, в результатах поиска —
видно, в какой папке найдено письмо). Для спецпапок (Trash/Junk/Drafts)
добавляются CSS-классы `folder-trash/junk/drafts`.

Файлы лежат внутри `find_from/` и подключаются его `find_from.php`
(отдельной настройки не требуют).

## Локализация

en_US, ru_RU. Метка `infolder` используется как тултип бейджа
(`В папке: $folder`).

## Установка

```bash
scp -r find_from/* root@mail.example.tld:/opt/www/roundcubemail/plugins/find_from/
```

и добавить `'find_from'` (при использовании — также `'contextmenu'`) в
`$config['plugins']` конфига Roundcube.
